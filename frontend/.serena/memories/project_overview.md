WheelCheck frontend is a Next.js 16 + React 19 + TypeScript + Tailwind CSS app for finding, viewing, reporting, and administering accessible places in Malaysia. It uses next-intl for i18n, client-side hooks/components under src/, and app router pages under src/app/[locale]. Key areas: src/app for routes, src/components for UI/map/place/report components, src/hooks for client data hooks, src/lib for API/types/constants, and src/messages for locale JSON files.

# WheelCheck Roadmap

## Phase 1: MVP (Current)
Core accessibility checking functionality.

### Backend
- [ ] Spring Boot Kotlin project setup with PostGIS
- [ ] Place CRUD API (search, create, update)
- [ ] Accessibility review submission API
- [ ] Photo upload with EXIF stripping
- [ ] Nearby place search (spatial query)
- [ ] Anonymous submission support
- [ ] Rate limiting
- [ ] OpenAPI documentation
- [ ] OSM Overpass data import script
- [ ] Docker Compose setup

### Frontend
- [ ] Next.js PWA with offline support
- [ ] Map view (Leaflet + OSM tiles)
- [ ] List view (accessible alternative)
- [ ] Venue detail page with accessibility breakdown
- [ ] Quick report flow (< 30 seconds)
- [ ] Photo upload UI
- [ ] Confirm/deny reports
- [ ] Bilingual support (BM + EN)
- [ ] WCAG 2.2 AA compliance
- [ ] Service Worker for offline

## Phase 2: Community
User engagement and data quality.

- [ ] User registration (optional)
- [ ] Contribution history
- [ ] Gamification (points, badges, levels)
- [ ] Venue owner self-certification portal
- [ ] Report outdated information
- [ ] Community verification system (upvote/downvote)
- [ ] Trusted reviewer program

## Phase 3: Expansion
Advanced features and integrations.

- [ ] Route planning between accessible venues
- [ ] Real-time reports ("elevator broken today")
- [ ] Integration with accessibility.cloud
- [ ] Mandarin + Tamil language support
- [ ] Data export API (for other apps)
- [ ] Government data integration (UBBL compliance)
- [ ] Partnership portal for disability organizations
